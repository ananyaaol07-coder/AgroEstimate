# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Email the project maintainer at [ananyaaol07@gmail.com](mailto:ananyaaol07@gmail.com) with:

- a description of the issue;
- steps to reproduce it;
- the affected page, feature or Firestore collection; and
- any suggested mitigation.

Please do not include passwords, Firebase service-account credentials, authentication tokens or personal user data in the report.

We will acknowledge the report, investigate it, and coordinate a fix before public disclosure when appropriate.
